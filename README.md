# DecodeLabs Full Stack Project 2

## Student Information System

### Project Description
This project is developed as part of the DecodeLabs Full Stack Development program. It demonstrates backend API development using Node.js and Express.js.

### Features
- Add student details
- View all students
- Search students
- Update student details
- Delete student details
- Student dashboard and statistics
- Input validation

### Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON

### How to Run
1. Install Node.js.
2. Open the project folder in the terminal.
3. Run `npm install`.
4. Run `node server.js`.
5. Open `http://localhost:3000` in your browser.

### Project Objective
To understand backend development, REST API endpoints, server-side logic, and data validation.
